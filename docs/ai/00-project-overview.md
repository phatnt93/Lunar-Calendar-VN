# Project Overview

## 1. Project Name
Lịch Vạn Niên - VN (lunar-calendar-vn)

## 2. Description
A Chrome extension built with Plasmo that provides a Vietnamese Lunar Calendar. It displays solar and lunar dates, daily quotations, zodiac hours (giờ hoàng đạo), and solar terms (tiết khí). It also includes utilities for converting between solar and lunar dates.

## 3. Core Features
- **Monthly View**: Displays a full month grid with solar dates and corresponding lunar dates.
- **Detailed Day View**: Shows detailed information for the selected date, including Can Chi (day, month, year), Solar terms, and Zodiac hours.
- **Daily Quotations**: Shows a daily quote based on the day of the year.
- **Date Conversion**: Utilities to jump to a specific solar date or convert between solar and lunar dates.
- **Offline Capable**: Core algorithms and data are bundled with the extension.

## 4. Target Audience
Vietnamese users who need to track lunar dates and related traditional calendar information directly from their browser.
